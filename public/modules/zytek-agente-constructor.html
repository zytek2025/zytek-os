PIPELINE DE EJECUCION
7 AGENTES ESPECIALIZADOS
🧠 Orquestador max 800 tokens
Recibe tu mensaje, lo analiza y devuelve un JSON con el plan: que agentes activar y en que orden. Al final consolida todos los resultados en un resumen de 3-4 lineas.
🔍 Analista max 1000 tokens
Audita el estado del codigo. Detecta gaps con impacto CRITICO / ALTO / BAJO. Cita funciones reales del sistema como renderCompras() o setRepCat().
🎨 Diseñador UX max 800 tokens
Define flujos de navegacion, propone IDs de elementos DOM, y revisa que la experiencia sea mobile-first (touch targets minimo 44px). Usa el design system existente de ZytekOS.
⚙️ Desarrollador max 4000 tokens
Genera el codigo HTML/CSS/JS completo usando el delimitador ===ARCHIVO_INICIO:nombre.html===. Cero placeholders, cero alert(), null guards en todo el DOM.
🧪 QA Engineer AUTO
Se activa automaticamente despues del Desarrollador. Corre 7 checks estaticos locales + revision con IA. Devuelve QA PASS, QA WARN o QA FAIL con la lista exacta de bugs.
✅ Validador max 800 tokens
Verifica la logica funcional: la implementacion hace lo que se pidio? Detecta edge cases no cubiertos y propone correcciones especificas con codigo exacto.
📋 Documentador max 800 tokens
Genera la documentacion tecnica: que se hizo, como integrarlo en los archivos existentes, archivos afectados y los pasos exactos para el siguiente sprint.

ARQUITECTURA SOLID
S
Single Responsibility
7 servicios, uno por responsabilidad: ApiService QAService StateService FileService UIService AgentRegistry Orchestrator
O
Open / Closed
AgentRegistry.register(new IAgent({...})) para agregar agentes sin tocar el Orchestrator ni ningun otro modulo.
L
Liskov Substitution
Todos los agentes son instancias de IAgent. El Orchestrator puede usar cualquiera sin saber que agente especifico es.
I
Interface Segregation
IAgent solo expone run(messages). Interfaz minima, sin metodos innecesarios. El Orchestrator solo llama .run().
D
Dependency Inversion
Orchestrator depende de AgentRegistry, QAService, UIService. Nunca de fetch() ni de agentes concretos.
BACKENDS DISPONIBLES
☁ Anthropic API
Modelos: Sonnet 4 · Opus 4 · Haiku 4.5
Requiere: API key sk-ant-...
Pros: mas preciso, mejores archivos grandes
Contras: costo por token, requiere internet
🦙 Ollama local
Modelos: cualquiera instalado localmente
Requiere: OLLAMA_ORIGINS="*" ollama serve
Pros: gratis, privado, sin internet
Recomendado: qwen2.5-coder:7b
